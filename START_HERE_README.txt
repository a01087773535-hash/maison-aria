========================================================
  MAISON ARIA - Store OS  실행 가이드
========================================================

[Windows에서 실행하는 방법 · 3가지 중 하나 선택]

▶ 방법 1) 가장 쉬움
   1. 이 폴더를 압축을 완전히 푼 뒤 폴더 자체를 엽니다.
   2. start_app.bat  파일을 더블클릭.
      - 처음 실행이면 npm install 이 자동으로 실행됩니다. (1~3분 소요)
      - "http://localhost:3000" 이 표시되면 브라우저로 접속.

▶ 방법 2) .bat 이 안 열릴 때
   start_app.cmd 를 더블클릭 하세요. (내용은 start_app.bat과 동일)

▶ 방법 3) SmartScreen / 정책으로 위 둘이 막힐 때
   1. 이 폴더에서 Shift + 마우스 오른쪽 클릭 → "여기서 PowerShell 창 열기"
   2. 다음 명령 실행:
        powershell -ExecutionPolicy Bypass -File .\start_app.ps1


[bat 파일이 안 열리는 대표 원인 & 해결]

1. Node.js 가 설치되어 있지 않음
   → https://nodejs.org 에서 LTS 버전 설치 후 다시 실행.

2. 압축을 "미리보기 상태"에서 그대로 더블클릭함
   → 반드시 압축을 완전히 풀고, 풀린 폴더 안에서 실행할 것.
     (압축 안에서 실행하면 npm install 이 실패해 창이 즉시 닫힙니다)

3. Windows Defender / SmartScreen 이 차단
   → 파일 마우스 오른쪽 → 속성 → "차단 해제" 체크 후 확인.
   → 또는 방법 3(PowerShell)으로 실행.

4. 창이 순식간에 닫혀서 원인이 안 보인다
   → 새 start_app.bat 은 오류가 나면 창을 유지하고 원인을 표시합니다.
     그래도 닫힌다면 cmd 창을 먼저 열고,
     cd  <이 폴더 경로>
     start_app.bat
     순서로 실행해 메시지를 확인.

5. 3000 포트가 이미 사용 중
   → 다른 서버가 3000 포트를 쓰는 중일 수 있습니다.
     해당 프로그램 종료 후 다시 실행하거나,
     server.js 안 PORT 값을 3001 등으로 변경.
